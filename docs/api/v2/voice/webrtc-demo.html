WebRTC softphone demo

Test page for the WebRTC softphone integration: paste the credentials returned by GetWebRTC, connect, and place a call with MakeTTSCall. Everything runs in your browser; the credentials go only to the Velip WebRTC server and are not stored.

1. Credentials

Paste the whole JSON: its ice_servers include the TURN relay used on networks that block UDP. Use test credentials. Anyone who has sipsecret can register as this agent; call GetWebRTC with reset=1 (POST) to replace it. Do not open the same credentials in another tab: the last registration receives the calls.

3. Place a test call (from your backend or a terminal)

  1. Get the credentials (your account must have WebRTC enabled by Velip): 
    curl -X POST 'https://vox.velip.com.br/api/v2/GetWebRTC.php' \
  -H 'Authorization: Bearer YOUR_TSID' -H 'Content-Type: application/json' \
  -d '{ "userid": "agent01" }'
  2. Paste the JSON above and click Connect. Wait for Ready.
  3. Place the call with dest = the sipname and dest2 = the number to call: 
    curl -X POST 'https://vox.velip.com.br/api/v2/MakeTTSCall.php' \
  -H 'Authorization: Bearer YOUR_TSID' -H 'Content-Type: application/json' \
  -d '{ "type": "3", "priority": "-1", "dest": "SIPNAME", "dest2": "5511999999999",
        "content": "tf19472806", "contentfail": "tf481661861", "rec": "300", "timelimit": "300", "free": "1" }'
  4. This page rings and answers; then the number in dest2 is dialed.
